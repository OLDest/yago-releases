# Обновления YaGo 0.3.0

Публичные загрузки: https://github.com/OLDest/yago-releases/releases/latest

Приложение проверяет открытые релизы при запуске и каждые 30 минут, пока работает. Вход GitHub не нужен. Кнопка «Обновл.» открывает проверку, прогресс, отмену и установку. Автозагрузку можно отключить. Android автоматически скачивает только по Wi-Fi без тарификации; вручную можно скачать через любую сеть.

До установки проверяются подпись Ed25519, имя, версия, размер и SHA-256 файла. Ключ подписи прежний. В Windows помощник заменяет EXE и перезапускает только YaGo; перезагрузка компьютера не требуется. Помощник откатывает файл, если новое приложение не подтвердило первый кадр за 30 секунд. Папка программы должна быть доступна пользователю для записи. Ошибки: state/updates/<версия>/installer-*/error.txt.

Android проверяет подпись манифеста, SHA-256, пакет, версию и сертификат APK. Установку подтверждает пользователь в системном окне. Если Android попросил разрешить установку из YaGo, дайте разрешение, вернитесь и снова нажмите «Установить». Идентификатор пакета и ключ прежние; обновление поверх старой версии сохраняет вход.

Для старого клиента 0.2.0 выпускается совместимый релиз в прежнем закрытом репозитории. После установки 0.3.0 клиент обращается только к публичному источнику и не читает сохранённый токен GitHub. Также можно установить 0.3.0 вручную из публичного релиза.

## Выпуск

Перед выпуском выполните fetch веток/тегов и сверьте актуальные версии в обоих
репозиториях: приватном OLDest/yago и публичном OLDest/yago-releases. Не выбирайте
версию только по локальной копии. Сверьте исходный коммит, версию приложения,
Android versionName/versionCode, подпись, подписанный манифест и реальные файлы.

Завершение выпуска включает тег исходников на точном коммите, публичный релиз,
совместимый релиз прежнего приватного источника и обновление стандартных локальных
YaGo.exe/YaGo-android.apk вместе с контрольной суммой. Для приватного источника
подписывается отдельный манифест с repo=OLDest/yago; публичный использует
repo=OLDest/yago-releases. Бинарные файлы остаются одинаковыми. Старые релизы
и их файлы не перезаписываются. Запущенную установленную копию не заменяйте
прямой записью: её обновляет штатный установщик.

Исходный рабочий Git остаётся приватным. В OLDest/yago-releases размещаются готовые EXE/APK, лицензии, контрольные суммы, подписанный updates.json и архив соответствующих исходников по GPL-3.0-only. Архив строится через git archive из коммита релиза; история Git, локальные инструменты, состояние, ключи и токены в него не входят.

Поднимите Version, Android versionName/versionCode и -version в build-android-native.ps1. Соберите оба файла, подпишите:
`rtk proxy node scripts/sign-update.cjs .tools/release-vX.Y.Z X.Y.Z`.
Опубликуйте новый релиз vX.Y.Z в OLDest/yago-releases, включая updates.json. Старые релизы не перезаписывайте.

Приватные ключи остаются в .tools/update-signing/private.pem и .tools/android-signing/yago-test.keystore. Сохраните их резервную копию отдельно. Публичный ключ закреплён в приложении.

Проверены Go-тесты, shuffle без повторов, навигация назад, anonymous HTTP, Ed25519/SHA-256, Windows-иконка и кнопка шафла, APK v2/v3 и ARM64/ARMv7 с 16 КиБ ELF. Запуск приложения на физическом Android подтверждён пользователем. Автоматическая замена не гарантирует восстановление после аварийного отключения питания.
