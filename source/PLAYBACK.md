# Качество и управление воспроизведением

## Качество MP3

Выпадающий список качества: Basic — MP3 192 кбит/с; HQ — лучший доступный полный MP3. Выбор заново загружает текущий трек, сохраняя позицию и паузу. Если MP3 192 недоступен, Basic не включается, текущее воспроизведение продолжается. Выбранный режим сохраняется. Фактический битрейт отображается отдельно; HQ может оказаться MP3 192, если это максимум сервиса.

Состояние воспроизведения восстанавливается после перезапуска. Описание, расположение checkpoint и ограничения: [PERSISTENCE.md](PERSISTENCE.md).

## Windows

Мультимедийные кнопки Next, Previous, Play/Pause, Stop, Volume Up, Volume Down и Mute работают глобально, пока YaGo открыт, в том числе при свёрнутом окне. Отдельные команды Windows MEDIA_PLAY и MEDIA_PAUSE также обрабатываются в окне приложения.

| Действие | Глобальная комбинация |
| --- | --- |
| Следующий трек | Ctrl+Alt+→ |
| Предыдущий трек | Ctrl+Alt+← |
| Пауза / продолжить | Ctrl+Alt+Пробел |
| Play | Ctrl+Alt+P |
| Пауза | Ctrl+Alt+O |
| Продолжить | Ctrl+Alt+R |
| Стоп | Ctrl+Alt+S |
| Громче | Ctrl+Alt+↑ |
| Тише | Ctrl+Alt+↓ |
| Mute / вернуть звук | Ctrl+Alt+M |

P/O/R/S/M — физические клавиши латинской раскладки; Windows регистрирует их по виртуальным кодам.

Громкость меняется только у YaGo, шаг — 10 процентных пунктов. Mute запоминает прежний уровень; повторное нажатие возвращает его. Изменение громкости снимает Mute. Пока YaGo занимает мультимедийные Volume/Mute, эти клавиши управляют YaGo вместо системного микшера. После закрытия регистрации освобождаются.

Если комбинация занята другим приложением, YaGo пишет её имя в статус и журнал. Доступные комбинации продолжают работать. Другая запущенная копия YaGo тоже может занять клавиши.

После Stop команда Play/Continue запускает выбранный трек заново. Обычная пауза сохраняет позицию. Previous при позиции больше трёх секунд возвращает к началу текущего трека, иначе идёт к предыдущему в очереди.

- Тесты HTTP: варианты только из ответа сервера, отсутствие 128 при единственном полном 320, отбрасывание preview/AAC, миграция сохранённого 128, возврат в авто при недоступном предпочтении.

- Нативное скрытое тестовое окно: команды Play, Pause, Stop, Next, Previous, Volume/Mute переданы через Windows subclass.
- На работающем Windows-приложении проверены Ctrl+Alt+↑, Ctrl+Alt+M, Ctrl+Alt+↓ из другого окна, переключение качества и отображение состояния.
- Все Go-тесты, реальный MP3 и go vet пройдены. Android APK проверен по подписи/ABI/ELF.
- Живой запрос к Яндексу пропущен: в доступном профиле Windows нет сохранённого входа YaGo. Запуск приложения на физическом Android подтверждён пользователем. Аппаратные Fn-клавиши отдельно не проверялись.
