# Android: результат сборки

Исторический отчёт 0.1.0. Актуальная сборка 0.10.0 описана в [ANDROID_0.10.0.md](ANDROID_0.10.0.md).

Файл: `YaGo-android.apk`, 11 522 864 байта (10,99 МиБ).

- Пакет: `com.yago.mobile`, версия 0.1.0, versionCode 1.
- Минимум: Android 8.0 / API 26 и OpenGL ES 3.0.
- Target SDK: 35.
- ABI: `arm64-v8a` и `armeabi-v7a` в одном APK.
- Подпись: локальный тестовый RSA-3072 ключ, проверка APK Signature Scheme v2/v3 успешна.
- SHA256 APK: `d53310b3c7567814249c5b47bf853bc2ef1eb4f119fb81ece384ed8c53121ace`.
- SHA256 сертификата: `33688c6c3a65e3c26c05282e1abb0a1f57155e20bd6f4a3a86eac9e4bc49b129`.

Проверено инструментами SDK/NDK: манифест, launch activity, обе ABI, присутствие JNI callback управления музыкой, подпись, zipalign и ELF LOAD alignment `0x4000` (16 КиБ). Внешние зависимости native-библиотеки — только системные Android `.so`; отдельный `libc++_shared.so` не нужен.

В APK включены лицензии Go-зависимостей, Gio, Oboe и уведомления LLVM/NDK. Данные входа сохраняются в закрытой области приложения в зашифрованном виде; AES-GCM ключ создаётся Android Keystore. Резервное копирование данных приложения отключено.

Go `verify.ps1` и `go vet ./...` прошли. Интеграционная проверка настоящего MP3 и аудиоустройства выполнена на Windows с нулевой громкостью. Проверено продвижение очереди без FrameEvent и игнорирование устаревшего события завершения. Исправлена гонка очистки при быстрых переключениях треков: закрытие теперь ждёт завершения загрузчиков и декодеров.

Портретный интерфейс 380×820 осмотрен в Windows-предпросмотре: стартовый экран, демонстрационная библиотека и раскрытый плеер. Для фона добавлены отдельный контроллер очереди, foreground media service, MediaSession, управление уведомлением/гарнитурой, аудиофокус и остановка при отключении наушников.

**На настоящем Android и эмуляторе приложение ещё не запускалось.** Не проверены Android Keystore на устройстве, полный вход в аккаунт, защищённые треки Яндекса, переключение сети и ограничения фонового режима конкретного производителя.

При ручной проверке: установить → войти по коду → найти трек → включить → свернуть → заблокировать экран → проверить паузу/следующий трек в уведомлении → развернуть → проверить восстановление входа после перезапуска. Кнопка «Назад» сворачивает приложение; удаление из недавних останавливает музыку.

JDK при компиляции Java в ограниченной Windows-среде печатал диагностическое сообщение об очистке ZipFileSystem (`AccessDeniedException` на `android.jar`); код возврата компилятора был 0, классы собраны, D8 и проверки готового APK прошли. Это диагностическое сообщение сборщика, а не результат проверки на телефоне.

Очистка: удалены пять воспроизводимых архивов SDK/NDK/JDK и исполняемый файл предпросмотра — 1 118 783 903 байта, без корзины. APK, контрольная сумма, исходники, AAR, установленные инструменты, кэши, состояние и ключ подписи сохранены. Диагностический лог предпросмотра сохранён.
