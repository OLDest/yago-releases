# Фоновый буфер «Моей волны» — 0.9.0

Когда начинается первая песня из обычной начальной пятёрки, YaGo в фоне получает ещё 15 уникальных разрешённых песен. Дальше пополнение запускается, когда после текущей песни остаётся меньше пяти доступных треков. Это загрузка списка и метаданных: аудиофайлы всех будущих песен в RAM не загружаются.

API обычно возвращает по пять песен; загрузчик собирает 15 несколькими последовательными запросами. Уже полученные ID передаются в `queue`, повторы и заблокированные исполнители отфильтровываются. Одновременно выполняется только одно пополнение. При повторяющихся или заблокированных ответах действует предел восьми итераций; при ошибке сохраняется уже полученная часть, а повтор откладывается на 30 секунд. Общий таймаут одной фоновой загрузки — 45 секунд.

Новая часть дописывается в хвост. Текущий аудиопоток, позиция, пауза, номер проигрывания и порядок существующего хвоста не меняются. Кнопка «Далее» работает, пока идёт запрос. Если пользователь быстро дошёл до конца ещё до ответа, загрузчик продолжает тот же запрос и включает следующую песню после его завершения. При Stop или смене источника запрос отменяется, поздние ответы игнорируются.

У каждой песни сохраняется собственная пара session/batch для правильных откликов Яндексу. Сессия, полученная при восстановлении истёкшей радиосессии, не подменяет контекст уже играющей песни. Метаданные записываются вместе с очередью; прежние файлы состояния без этого поля продолжают открываться.

Память ограничена: после пополнения остаётся до пяти прошлых песен для «Назад». В обычном последовательном режиме — около 25 записей очереди: пять прошлых, текущая и до 19 будущих. Жёсткий предел — 64 записи, в том числе при изменении шафла во время запроса. Новые записи шафла добавляются отдельно, без перестановки уже существующего порядка. Список волны и его контексты используют те же массивы, когда отдельный обновлённый список F5 не открыт.

Ручное «Обновить / F5» сохраняет прежнюю семантику: новый список показывается отдельно, текущая песня продолжает играть. Фоновое продолжение старой очереди не перезаписывает этот список. Выбор песни из нового списка переключает очередь и отменяет старую фоновую загрузку.

Проверки: автозапуск подгрузки при старте первой песни; сбор 15 из трёх ответов; работа Next во время загрузки; порог 5/4 будущих песен; фильтрация повторов и блокировок; ошибка без остановки аудио; сохранение batch; совместимость состояния; сохранение отдельного F5-списка и шафла; 300 пополнений с ограниченной очередью и 50 смен шафла с соблюдением жёсткого предела. Новые зависимости и фоновые таймеры не добавлены — повтор использует существующий тик приложения.
