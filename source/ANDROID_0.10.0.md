# Android 0.10.0

Пакет `com.yago.mobile`, versionCode 23. Android 8.0+, ARM64 и ARMv7, OpenGL ES 3.0.

Перенесены профили Яндекса/Звука, режим «Все», смешанная волна, общие выпадающие
язык/настроение, отдельные параметры сервиса, объединённые библиотека и история.
Выбор общих параметров сразу сохраняет оба аккаунта и обновляет следующие треки;
текущее воспроизведение и исходный контекст feedback сохраняются.

Вход в Звук открывает Android WebView только в отдельном процессе `:zvuk_auth`.
После входа, отмены или таймаута окно уничтожается, данные WebView очищаются,
процесс входа завершается. Плеер, аудио и обычный интерфейс WebView не используют.
Вход подтверждается неанонимным профилем с origin `https://zvuk.com`.
Токен передаётся в память основного процесса через защищённый signature-permission
broadcast с идентификатором текущего запроса. Activity не экспортируется;
нет JavaScript-interface, чтения чужих браузеров, обхода TLS или логирования токенов.

Оба токена сохраняются AES-GCM через Android Keystore в разных записях.
Прежняя запись `token` Яндекса остаётся прежней, Звук использует `zvuk-token`.
Ключ подписи APK сохранён: SHA-256 сертификата
`33688c6c3a65e3c26c05282e1abb0a1f57155e20bd6f4a3a86eac9e4bc49b129`.

Проверено 18.11.2026: компиляция Go для обеих ABI, Java/D8, подпись APK v2/v3,
manifest, JNI callback, zipalign и ELF 16 KiB. Размер APK 10 880 385 байт.
Go-тесты и vet проходят на Windows. Нативные зависимости Android — системные;
новые браузерные библиотеки, изображения и шрифты в APK не добавлены.
Подключение Звука на Android подтверждено пользователем 18.11.2026.

Публикация: https://github.com/OLDest/yago-releases/releases/tag/v0.10.0 .
Нативный клиент обновлений без токена GitHub скачал APK и Windows EXE из публичного
релиза; подпись Ed25519 и SHA-256 обоих файлов подтверждены. Текущая версия 0.10.0
не получает повторное предложение обновления. Исходники коммита `2894699` включены
в отдельный архив; ключи, состояние и история Git туда не входят.

Установка поверх предыдущей версии сохраняет данные приложения. Проверка нового
входа: «Профили → Подключить Звук», обычная авторизация, возврат в YaGo, поиск и
воспроизведение; затем «Все», общие параметры и повторный запуск приложения.
