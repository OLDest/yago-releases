# YaGo 0.11.7

- Повторное нажатие на сердечко снимает лайк. При ошибке сервиса состояние не переключается ложно.
- При блокировке сохраняются название и исполнитель; они отображаются в списке заблокированных треков после перезапуска.
- Названия сохраняются при переключении и объединении музыкальных сервисов без смешивания их идентификаторов. При разблокировке сохранённое название удаляется.
- Старые блокировки совместимы. Для известных локально старых треков используются названия; для неизвестных остаётся ID.

Проверены полный набор Go-тестов и vet, сохранение/загрузка настроек, смешанные сервисы, блокировка/разблокировка и переключение лайка. Собраны Windows GUI и Android ARM64/ARMv7; проверены прежняя подпись APK и выравнивание16КиБ. Пакет Android и ключи подписи сохранены.
