# Исправление «Моей волны» — 0.1.1

Причина: общий разбор API требовал поле result. Сессионный endpoint волны может возвращать radioSessionId, batchId и sequence прямо в корне JSON. Такой ответ ошибочно считался пустым.

Исправлено: оба формата ответа для создания сессии и следующей порции треков. Отсутствующие/пустые треки и идентификатор новой сессии проверяются отдельно. HTTP 204 для событий воспроизведения принимается без разбора JSON. Для остальных API обёртка result остаётся обязательной.

Проверка до исправления: direct_new и direct_continue падали с «пустой ответ Яндекса». После исправления прошли все тесты verify.ps1 (включая настоящий MP3 и аудиоустройство на Windows) и go vet ./....

Живой запрос к Яндексу пропущен: сохранённого входа YaGo на ПК нет. Исправление подтверждено регрессионными ответами HTTP, а не прослушиванием аккаунта пользователя.
